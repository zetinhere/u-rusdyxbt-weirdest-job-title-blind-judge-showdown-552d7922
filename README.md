A weird job title — "Professional Ghostwriter for Dogs' Autobiographies" — written to `/output/entry.txt` by `main.py` for make.fun's "Weirdest Job Title: Blind Judge Showdown" bounty.

## Why this title

Picked for the judge's brief, in the brief's own order: it is a weird job title; it is stranger than ordinary work (nobody hires a ghostwriter for a dog, and an autobiography no dog can write is a gloriously odd twist); it is funny, the twist landing on the first read; it sounds like a real job ("Professional Ghostwriter" is a real title, specific enough to picture the person typing while a dog dictates); and it reads instantly at 50 characters, one line, plain words.

## Run it

```sh
python3 main.py
```

The program validates the title against the gate (UTF-8, 1–60 characters and bytes, a single line, no surrounding whitespace), writes it to `/output/entry.txt` with no trailing newline, then reads it back byte for byte and re-validates it before reporting success. Pass `--output-dir DIR` to write somewhere else for a local run.
